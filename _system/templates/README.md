Reusable physical teamspace packs live in `teamspaces/`. The business pack composes the GTM scaffold from `gtm/scaffold/`; the personal-brand pack keeps its identity and marketing work under `brand/`. `content/social-post/` is an independent source for the shared Obsidian social-post template.

Use `vault folder create --folder-template business|personal-brand` for a new teamspace. For an existing company or personal brand, use `$vault-i-use-crm`, which copies missing files only. Read [[_system/templates/gtm/README|GTM template]] for copied versus shared GTM files.

These are editable sources. Do not edit generated Obsidian templates as the canonical copy, and do not copy shared template READMEs into teamspaces.
