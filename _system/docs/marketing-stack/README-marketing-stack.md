The live stack is [[stack]]. It is shared across marketing identities in this Vault. Keep one record for each tool or integration, with its purpose, which identities use it, current status, and a link to non-secret configuration instructions.

Do not copy this folder into a company or brand context. The business and personal-brand folder packs may point here, but they must not create their own `marketing-stack/` or `stack.md`. If an identity uses a different account or setting, describe that difference in the shared row or link to its existing context-owned configuration. Never store credentials here.

Keep positioning, campaigns, offers, funnels, and relationship records in their owning context. A shared tool does not make the companies' GTM plans or CRMs shared.
